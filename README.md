# 🎵 Melodify

A full-stack music streaming platform built with vanilla JavaScript, HTML, and CSS — featuring persistent user preferences, curated album browsing, and a dynamic in-app player experience.

---

## ✨ Features

- **🏠 Home Dashboard** — Featured hero track, trending ticker, language chips, and curated album grids
- **🔍 Smart Search** — Real-time search across songs, artists, albums, and languages
- **❤️ Favourites** — Like songs and build a personal collection
- **📃 My Playlist** — View and play your full song library in one place
- **🎧 Persistent Player** — Sticky bottom player with play/pause, skip, seek, and volume control
- **📊 Listening Stats** — Track recently played songs and listening activity
- **🌐 Language-Based Browsing** — Discover music organized by language/genre
- **📱 Responsive Sidebar Navigation** — Clean, icon-driven navigation across sections

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 |
| Styling | CSS3 |
| Interactivity | Vanilla JavaScript (ES6+) |
| Icons | Font Awesome 6.5.0 |

No frameworks, no build tools — pure client-side implementation.

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/yakkalakarthikeya/melodify.git
   ```
2. Navigate to the project folder
   ```bash
   cd melodify
   ```
3. Open `html.html` in your browser — no build step or server required

---

## 🎯 Core Sections

- **Home** — Hero spotlight, trending ticker, Song of the Day, recently played, and album grids
- **Search** — Instant filtering by song, artist, album, or language
- **Favourites** — Manage liked songs with one-click add/remove
- **My Playlist** — Full song library with playback controls

---

## 📌 Notes

- User preferences (favourites, recently played) persist across sessions
- Player supports seek, skip, and real-time progress tracking
- Fully responsive layout adaptable to different screen sizes
